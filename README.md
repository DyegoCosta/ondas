# Ondas

App Android para registrar ondas de calor na menopausa: um toque registra, a anotação é opcional e o histórico fica no aparelho. O app não pede acesso à internet.

**Instalar a versão mais recente:** abra no Android
https://github.com/DyegoCosta/ondas/releases/latest/download/ondas.apk

Cada push na `main` compila o app e publica um novo Release. Kotlin + Jetpack Compose, minSdk 26.
